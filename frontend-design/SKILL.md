# Frontend Design

Ground the design in the product, audience, content, and the interface's primary
job. Preserve an explicit visual direction from the brief. Where the brief is
open, choose one coherent concept rather than falling back to common AI patterns
such as generic gradient statistics, decorative numbering, or interchangeable
serif editorial layouts.

Before implementation, establish a compact direction for color, typography,
layout, and one memorable signature element. Keep supporting elements quiet so
the signature has room to work. Match execution complexity to the concept;
minimal work needs precise spacing and type, while maximal work must earn its
ornament and motion.

Use real content where available. Write interface copy from the user's point of
view with consistent action names, concrete errors, and useful empty states.

Implement the direction using the project's existing stack and conventions.
Maintain responsive layouts, visible keyboard focus, readable contrast, and
reduced-motion behavior. Inspect the rendered result at representative sizes and
iterate on visible problems before considering the design complete.
